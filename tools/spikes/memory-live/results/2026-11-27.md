## Bugs found by the live turns, fixed in this change

1. The transcript hint put `--machine` after the command, but it is a global
   option. The agent got "flag provided but not defined", then worked it out.
   The recall note, the tool description, the instructions, the dream
   procedure and the CLI help now give this form, with the turn's own CLI
   path:

   ```sh
   dieter --machine MACHINE card transcript --last 40 CARD
   ```

2. `dieter memory search --local` returned no saved memories. They are
   replicated, so every search now answers them from the local copy.
3. The dream conversation was indexed. It quotes every memory, so it became
   the top hit for everything. Dream conversations are no longer indexed, and
   reconciliation drops any that were.
4. The CLI printed a doubled `… …` before snippets.

# Selected Material icons

These eight vector definitions come from JetBrains Compose Material Icons 1.7.3
(`material-icons-extended-1.7.3-sources.jar`), originally authored by the Android
Open Source Project. Their package name and formatting were changed; the vector
paths are unchanged. See [LICENSE.txt](LICENSE.txt) and each source header.

Keeping only the icons used by the spike avoids Kotlin/Native compiling the
entire extended icon library. Standard icons still use `material-icons-core`.

Agent mail — UI mockup

An Outlook-style mailbox mapped onto Dieter's Mac shell: app sidebar, message list, reading pane. It is read-only by design: no reply or compose, only Archive, Delete, Flag, Mark unread and Open conversation. Phones use a fifth tab with a list that pushes the message. Tablets and iPads show the list and the message side by side.
